# 🐦🚲 鹈鹕海岸骑行 · Pelican Coast Ride

戴头盔墨镜、脖子系红围巾的鹈鹕在海岸公路上骑车抓鱼 —— 纯浏览器 3D（Three.js r128），无需构建。

**在线游玩：** https://xiaol201022-debug.github.io/pelican-bike-3d/

## 特色
- 红围巾：Verlet 布料物理（结构/剪切/弯曲约束 + 风阻、颤动、身体碰撞）
- 昼夜循环：黄昏 → 星空月夜 → 黎明，流星、银河、月光
- 海面 Gerstner 波浪 + 菲涅尔反射 + 岸边碎浪泡沫，灯塔光束、帆船、海鸥
- 双骨骼 IK 踩踏板、展翅滑翔、抬前轮
- 5 种镜头：追尾、侧面、航拍、电影运镜（含遮幅）、鹈鹕墨镜视角
- WebAudio 实时合成音乐与音效，节奏跟随踏频，夜晚音色变暗
- 14 个成就（本地保存）、自动驾驶追鱼、触屏按钮、按帧率自适应画质

## 操作
| 键 | 动作 |
|---|---|
| W / S | 加速 / 减速 |
| A / D | 变道抓鱼 |
| 空格 | 跳跃 |
| T | 展翅抬前轮 |
| C / 1-5 | 切换镜头 |
| H | 成就 |
| M | 静音 |

不操作 5 秒后自动驾驶接管。

## 本地运行
```
python -m http.server 8765
```
然后打开 http://localhost:8765
